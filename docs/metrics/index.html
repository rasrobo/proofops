The numbers, from the people who opted in

Every figure here arrived through proofops share --enable — an explicit opt-in that prints the exact payload first. Installs that never opt in are simply not counted, which is the honest denominator: this page reports its own coverage, not the internet's.

What this page proves. That this many installs opted in and reported these cumulative counts. It does not prove the counts are true, that the work verified was important, or that a single defect was caught — a check that passes is not a defect avoided.

What it can never contain. No customer names, no repository or file paths, no hostnames, no plan names, no receipt contents, no command output, no email addresses. The payload is six fields with an allow-listed version and platform; the sanitizer that enforces it is tested, and the server refuses anything else.
